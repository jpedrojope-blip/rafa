# Page topology

1. Hero: full viewport, centered copy, fixed bottom location/scroll cue. Static plus scroll fade/parallax.
2. Philosophy: `340vh` scroll track with `100vh` sticky panel. Scroll-driven word reveal, blur, gold emphasis and progress line.
3. Capabilities header: border-top divider, “What we build” plus “Capabilities”.
4. Capability 02: `300vh` sticky split card. Scroll-driven SVG draw and word reveal.
5. Capability 03: same structure; browser/Core Web Vitals SVG.
6. Capability 04: same structure; server-rack SVG.
7. Capability 05: same structure; four-node infrastructure SVG.
8. Contact: centered CTA with glow, blinking cursor and mail link.
9. About teaser and footer: centered links, no extra interaction beyond hover color.

All sections share dark background, Geist/Geist Mono typography, amber `#FFB100` accent, and fixed grain overlay.
